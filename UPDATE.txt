HANDWRITTEN TITLE UPDATE

Extract this ZIP, then upload index.html and sw.js together to your Retro-walkman GitHub repository, replacing the existing files. Commit the upload and wait for GitHub Pages to publish. Open the player online, close it and reopen so the updated offline version can activate.

The track title now uses a flowing handwritten font, using the phone's built-in cursive font with handwriting font fallbacks. It works offline and needs no extra font files. Title size and spacing leave room for the artist name. Playback, animation and the cassette layout stay as before.

Only title CSS and the offline cache version changed. To undo, revert the upload commit in GitHub. Code comparison confirmed that the playback script is unchanged. The final font appearance depends on installed device fonts and should be checked on your phone.
